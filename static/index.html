Deployment Guide
Deploy to Vercel

Get your own instance running in under 5 minutes.

1

Import the project

Download the ZIP file and drag the folder into vercel.com/new or run vercel --prod from the terminal inside the project folder.

2

Set environment variables

In Vercel dashboard → Settings → Environment Variables, add: TELEGRAM_BOT_TOKEN, SHRINK_API, SUPER_ADMINS (comma-separated IDs), ALLOWED_GROUP_IDS, REDIRECT_LINK, OWNERS.

3

Register the webhook

After deploy, visit https://your-app.vercel.app/api/set_webhook once to register your bot's webhook with Telegram. You should see "ok": true.

4

Add your bot to groups

Add the bot to your Telegram groups and set the group IDs in ALLOWED_GROUP_IDS. Make sure the bot is an admin in those groups for /ban and kick features to work.

5

Use the Like API

Hit https://your-app.vercel.app/like?uid=YOUR_UID&region=BD from any browser, script, or HTTP client to send likes. Returns a JSON response with before/after counts.
